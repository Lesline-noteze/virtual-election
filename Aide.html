Comment voter en ligne

Guide simple et clair pour vous orienter dans la procédure de vote numérique

Avant de commencer

  • Assurez-vous d'avoir une connexion Internet stable.
  • Préparez vos pièces d'identité et les informations demandées.
  • Consultez les documents officiels pour connaître les enjeux.

Procédure de vote en ligne

Étape 1 — Inscription

Suivez la procédure d'inscription :

  1. Cliquez sur Inscription et ouvrez le formulaire.
  2. Remplissez tous les champs demandés avec attention.
  3. Relisez vos informations puis cliquez sur Soumettre.
  4. Conservez votre code d'identification et votre nom d'utilisateur.
Étape 2 — Connexion

Pour accéder à votre compte

  1. Cliquez sur Connexion.
  2. Entrez votre code d'identification et votre nom d'utilisateur.
  3. Validez pour accéder à l'interface de vote.
NB : les informations doivent correspondre à celles fournies lors de l'inscription.
Étape 3 — Vote

Procédure :

  1. Choisissez le type d'élection (présidentielle, législative, etc.).
  2. Sélectionnez le candidat de votre choix.
  3. Vérifiez les informations présentées dans la confirmation.
  4. Confirmez votre vote. Vous recevrez une confirmation anonyme et sécurisée.
Conseils rapides
  • Ne partagez jamais votre code d'identification.
  • Utilisez un appareil personnel pour voter.
  • Contactez l'assistance en cas de problème.
Conditions d'éligibilité (extraits)
Présidentielle
  • Âge minimum : 35 ans.
  • Nationalité requise.
  • Inscription sur les listes électorales.
Législatives
  • Âge minimum : 18 ans.
  • Jouir de ses droits civiques.
